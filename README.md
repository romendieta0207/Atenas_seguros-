# Atenas Seguros

Sitio web estático en HTML, CSS y JavaScript, basado en la plantilla de Figma
«Prueba WEB».

## Ver en local

Abre `index.html` en el navegador o ejecuta `python3 -m http.server 8000` y
visita <http://localhost:8000>.

## Publicar con GitHub Pages

1. Sube los archivos del proyecto a la rama `main`.
2. En **Settings → Pages**, elige **GitHub Actions** como fuente.
3. Después de publicar, el sitio estará disponible en
   `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Información pendiente de confirmar

- Teléfono y enlace de WhatsApp.
- Correo, ubicación, horarios, razón social y autorizaciones.
- Textos marcados como «por validar» en el pie de página.
