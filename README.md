# Atenas Seguros · Sitio web (propuesta 2)

Web estática (HTML, CSS y JS, sin dependencias) generada a partir del diseño de Figma "Prueba WEB".

## Ver en local
Abre `index.html` en el navegador, o ejecuta `python3 -m http.server 8000` y entra en http://localhost:8000

## Publicar con GitHub Pages
1. Crea un repositorio en GitHub y sube todos los archivos de esta carpeta a la rama `main`.
2. En **Settings → Pages**, en *Source*, elige **GitHub Actions**.
3. Cada vez que hagas push a `main`, el sitio se publica solo en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Estructura
- `index.html`: contenido de la página
- `css/styles.css`: estilos (colores y tipografías en `:root`)
- `js/main.js`: animación de cifras
- `img/`: imágenes optimizadas (WebP)
- `.github/workflows/pages.yml`: despliegue automático

## Pendiente de confirmar con el cliente
- Teléfono y enlace de WhatsApp (en el diseño aparece `099 854 544`, que tiene 9 dígitos)
- Correo, ubicación, horarios, razón social y autorizaciones (aparecen como "por confirmar")
- Textos marcados como "por validar" en el pie de página
